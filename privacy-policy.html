Política de Privacidade — LifUp

Última atualização: Abril de 2026

A LifUp ("nós", "nosso") desenvolveu a aplicação LifUp como uma aplicação gratuita financiada por anúncios. Esta página informa-te sobre as nossas políticas relativas à recolha, utilização e divulgação de dados pessoais quando utilizas a nossa aplicação.

1. Dados Recolhidos

A LifUp não recolhe nem armazena dados pessoais nos nossos servidores. Todos os dados de progresso do jogo (nível, missões, sombras, etc.) são guardados exclusivamente no teu dispositivo.

No entanto, os seguintes serviços de terceiros integrados na aplicação podem recolher dados:

  • Google AdMob — para exibição de anúncios recompensados. Pode recolher identificadores de dispositivo e dados de utilização para personalização de anúncios. Consulta a Política de Privacidade da Google.
  • Google Play Services — para funcionalidades básicas do Android.

2. Permissões Utilizadas

  • Localização (GPS) — utilizada opcionalmente para rastrear atividades físicas (corrida, caminhada). Nunca é enviada para servidores externos.
  • Notificações — para lembretes de missões diárias e alertas do sistema.
  • Acessibilidade — utilizada pelo Modo Foco para detetar apps em primeiro plano e bloquear distrações. Nenhum dado de utilização é transmitido externamente.
  • Internet — necessária para carregar anúncios.

3. Anúncios e GDPR

Utilizamos o Google AdMob para anúncios recompensados. Se resides no Espaço Económico Europeu (EEE), podes ser-te apresentado um pedido de consentimento para anúncios personalizados, em conformidade com o GDPR. Podes gerir as tuas preferências nas definições da aplicação Google em qualquer momento.

4. Partilha de Dados com Terceiros

Não vendemos, trocamos nem transferimos os teus dados pessoais para terceiros. Os serviços de terceiros listados acima operam de acordo com as suas próprias políticas de privacidade.

5. Segurança dos Dados

Os dados do jogo são armazenados localmente no teu dispositivo usando AsyncStorage. Podes fazer backup e restaurar os teus dados através das opções nas Definições da aplicação.

6. Crianças

A LifUp não se destina a crianças com menos de 13 anos. Não recolhemos intencionalmente dados de crianças.

7. Alterações a Esta Política

Podemos atualizar esta Política de Privacidade periodicamente. Recomendamos que reveja esta página regularmente. As alterações entram em vigor imediatamente após publicação.
